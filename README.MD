# Ejercicios de Kotlin

Repositorio con los 14 ejercicios de fundamentos de Kotlin

RUTH SARAHI RAMIREZ MORALES 

## Contenido

- `Ejercicio01.kt`: Variables, tipos de datos y actualización de información de usuario.
- `Ejercicio02.kt`: Cálculo de almacenamiento utilizado, disponible y porcentaje ocupado.
- `Ejercicio03.kt`: Cálculo de compra con subtotal, IVA (16%) y total.
- `Ejercicio04.kt`: Validación de edad para registro.
- `Ejercicio05.kt`: Menú de configuración con estructura `when`.
- `Ejercicio06.kt`: Control de acceso por contraseña con límite de intentos (`while`).
- `Ejercicio07.kt`: Cálculo de consumo acumulado y batería restante (`for`).
- `Ejercicio08.kt`: Operaciones matemáticas básicas con funciones.
- `Ejercicio09.kt`: Validación de datos de registro mediante funciones.
- `Ejercicio10.kt`: Clase `Usuario` e instanciación de objetos.
- `Ejercicio11.kt`: Clase `ProductoDigital` con constructor primario.
- `Ejercicio12.kt`: Encapsulamiento con la clase `Bateria`.
- `Ejercicio13.kt`: Herencia con `Dispositivo`, `Smartphone` y `Tablet`.
- `Ejercicio14.kt`: Polimorfismo con clases de `Notificacion`.
